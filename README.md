# Description

Emu-Hawk is a hardware emulator aimed at recreating the functionality of CDC Hawk Drive with a common MCU board. The Emu-Hawk uses the Teensy 4.1 for the MCU and a custom PCB for IO and level shifting. The teensy 4.1 was chosen for it's fast speed, plentiful IO, and wide codebase. The PCB is a simple two layer board with some level shifters, connectors, and switches to tidy everything into a neat package and can be put in a 3d printed case to make it look like an actual Hawk Drive. Importantly, this emulates the drive only! It needs to be plugged into a Hawk Drive compatible controller card. The idea is that it can be used to replace a faulty or absent drive, or help diagnose a faulty controller card.
